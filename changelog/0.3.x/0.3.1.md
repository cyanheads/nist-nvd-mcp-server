# 0.3.1 — 2026-09-20

## Added

- **Public hosted endpoint** — `https://nist-nvd.caseyjhand.com/mcp` is published as a `streamable-http` remote in `server.json` and documented in the README.

## Changed

- **Argument rejections classify `InvalidParams` (-32602)** instead of `ValidationError`, carrying `data.reason: "invalid_arguments"` and a schema-derived recovery hint.
- **Tool error text closes with `(reason … · not retryable)`** whenever the thrown error carries a `data.reason` or a boolean `data.retryable`.
- **A caller disconnect mid-call classifies `RequestCancelled` (-32011)** instead of an internal error.
- **The upstream NVD request URL no longer appears on client-facing `error.data`.**
- **The server card publishes the resolved session mode** (`stateless`) under `_meta`.
- Bun engines floor raised to `>=1.4.0`.
- Development skills moved from `skills/` to `framework-skills/`, so a plugin install no longer pulls them in as agent-facing skills.

## Fixed

- **Multi-arch Docker publish no longer fails on an arm64 build host** — the build stage cross-compiles instead of running under QEMU.
