# 0.1.0 — 2026-05-24

Initial release of `nist-nvd-mcp-server`.

## Added

- `nvd_search_cves` — search CVEs by keyword, severity (CVSS v2/v3/v4), CWE, date range, and CISA KEV status; convenience `pubDays`/`lastModDays` shorthands with auto-clamping at the 120-day API maximum
- `nvd_get_cve` — fetch up to 100 CVEs by ID; full or brief mode; `missingIds` parity check in response
- `nvd_search_cpes` — keyword and partial-match search against the NVD CPE dictionary
- `nvd_audit_cpe` — CPE-based CVE audit via exact `cpeName` or `virtualMatchString` with version range bounds; client-side severity filter
- `nvd_get_cve_history` — paginated change history for a CVE (CVSS revisions, status transitions, reference additions)
- `nvd://cve/{cveId}` resource — stable URI for injecting a single CVE record as context
- `NvdHttpClient` with token-bucket rate limiting (5 req/30s without key, 50 req/30s with key), automatic retry with backoff, and `Retry-After` header parsing
- Two-service architecture: `NvdCveService` (CVE + CPE audit + history) and `NvdCpeService` (CPE dictionary search)
