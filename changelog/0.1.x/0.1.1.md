# 0.1.1 — 2026-05-24

Full launch implementation on top of the initial scaffold. Includes the complete NVD tool surface, field-test fixes, and pre-launch polish.

## Added

- **`nvd_search_cves`** — search CVEs by keyword, severity (CVSS v2/v3/v4), CWE, date range, CISA KEV status; `pubDays`/`lastModDays` shorthands with 120-day auto-clamping
- **`nvd_get_cve`** — fetch up to 100 CVEs by ID; full/brief mode; `missingIds` parity tracking in response
- **`nvd_search_cpes`** — keyword and partial-match search against the NVD CPE dictionary
- **`nvd_audit_cpe`** — CPE-based CVE audit via exact `cpeName` or `virtualMatchString` with version range bounds and client-side severity filter
- **`nvd_get_cve_history`** — paginated change history for a CVE (CVSS revisions, status transitions, reference additions)
- **`nvd://cve/{cveId}`** resource — stable URI for injecting a single CVE record as context
- **`NvdHttpClient`** — token-bucket rate limiting (5 req/30s unauthenticated, 50 req/30s with API key), automatic retry with backoff, `Retry-After` header parsing
- **`NvdCveService`** and **`NvdCpeService`** — two-service architecture with normalized domain types
- 65 tests across all tools and resources

## Fixed

- **`nvd_search_cves`** date input validation: co-requirement check (start and end must be provided together) and inversion check (end before start) added with `missing_date_pair` and `date_range_inverted` error reasons
- **`nvd_search_cves`** date format: ISO 8601 timestamps now use `.000Z` suffix instead of `000 UTC+00:00`, matching the NVD API's accepted format
- **`nvd_get_cve`** array input validation: added `min(1)` constraint on the CVE IDs array
- **`nvd_get_cve`** missing IDs: `missingIds` array now surfaces in `queryMeta` and in `format()` output when any requested CVE was not returned by NVD
- **`NvdCveService`** error classification: single-CVE not-found and CPE-not-found errors now throw typed `McpError(NotFound)` instead of plain `Error` with attached `data`
- **`nvd_get_cve_history`** tool description: added explicit note that the NVD history endpoint is significantly slower without an API key (40–55s vs default 10s timeout); recommends `NVD_API_KEY` and/or `NVD_REQUEST_TIMEOUT_MS`
