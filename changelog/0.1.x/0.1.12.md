# 0.1.12 — 2026-06-20

## Changed

- **`@cyanheads/mcp-ts-core` `^0.10.6` → `^0.10.9`** — framework-maintenance bump; no server source or behavior change.
- **Vendored framework scripts/skills resynced to the 0.10.7–0.10.9 line** — adds the `check-dependency-specifiers` devcheck step (`scripts/check-dependency-specifiers.ts`, flag `--no-dep-specifiers`), which hard-fails on floating `latest`/`*`/pre-release dist-tag specifiers in `package.json`'s dependency sections and `bun.lock`'s `workspaces` map. ([cyanheads/mcp-ts-core#246](https://github.com/cyanheads/mcp-ts-core/issues/246))
- **`scripts/lint-packaging.ts`** — gains plugin-marketplace manifest validation (check 10) for `.claude-plugin/plugin.json` and `.codex-plugin/plugin.json`: non-empty descriptions, unscoped machine name in display fields, and the full `package.json` name in the `npx -y` install arg. ([cyanheads/mcp-ts-core#240](https://github.com/cyanheads/mcp-ts-core/issues/240))
- **`devcheck.config.json`** — added `packaging.pluginManifests: true`, enabling the new check-10 manifest validation; the "Packaging" gate now also runs when a plugin manifest is present.
- **`scripts/build-changelog.ts`, `scripts/devcheck.ts`, `scripts/check-framework-antipatterns.ts`, `scripts/check-skill-versions.ts`** — fresh-scaffold and worktree-deletion guards from the 0.10.7 framework release. ([cyanheads/mcp-ts-core#237](https://github.com/cyanheads/mcp-ts-core/issues/237), [cyanheads/mcp-ts-core#242](https://github.com/cyanheads/mcp-ts-core/issues/242), [cyanheads/mcp-ts-core#243](https://github.com/cyanheads/mcp-ts-core/issues/243))
