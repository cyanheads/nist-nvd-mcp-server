# 0.1.11 — 2026-06-12

## Changed

- **`@cyanheads/mcp-ts-core` ^0.9.21 → ^0.10.6** — adopted the framework's enrichment `total()` helper.
- **Enrichment total field** — `nvd_search_cves`, `nvd_search_cpes`, `nvd_audit_cpe`, and `nvd_get_cve_history` now report the pre-pagination count via `ctx.enrich.total(...)` under the `totalCount` key (was a self-declared `totalResults` enrichment field). The framework renders the "Total" trailer row, so each tool's `enrichmentTrailer` no longer declares a `totalResults` row.
- **`createApp()` identity** — `name` and `title` set explicitly to `nist-nvd-mcp-server` rather than relying on the package-name fallback (the scoped npm name).
- **`Dockerfile`** — added `ARG APP_VERSION` with an `org.opencontainers.image.version` OCI label, and a `HEALTHCHECK` that probes `/healthz` via a bun-native `fetch` (the slim runtime image ships no curl/wget).
- **`bundle` script** — chains `scripts/clean-mcpb.ts` after `mcpb pack` to run the official `mcpb clean` prune and strip dependency-shipped agent docs (`skills/`, `.claude/`, `.agents/`, stray `SKILL.md`) nested under `node_modules/` that root-anchored `.mcpbignore` patterns cannot reach. `scripts/lint-packaging.ts` gained the matching post-bundle content assertion.
- **`scripts/check-framework-antipatterns.ts`** — added a `z.coerce.boolean()` env-flag rule (`Boolean("false")` is truthy, so the flag can't be disabled via env — use `z.stringbool()`), and now skips comment lines so JSDoc naming an antipattern isn't flagged as a usage.
- **`.mcpbignore`** — root-anchored the ignore patterns (leading `/`) and added `/.agents/` and `/skills/`.
- **Plugin manifests** — `.codex-plugin/plugin.json` `interface.displayName` de-scoped to `nist-nvd-mcp-server`; both `.codex-plugin/plugin.json` and `.claude-plugin/plugin.json` resynced from 0.1.7 to the current version.
- **`nvd_search_cpes` error contract** — `missing_search_input` code corrected `InvalidParams` → `ValidationError`.
