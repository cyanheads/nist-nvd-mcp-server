# 0.1.8 — 2026-05-30

## Changed

- **`nvd_search_cves`, `nvd_search_cpes`, `nvd_audit_cpe`, `nvd_get_cve`, `nvd_get_cve_history`** — `queryMeta` output field removed; its values (`totalResults`, `returned`, `offset`, `missingIds`, etc.) now surface in a typed `enrichment` block reaching both `structuredContent` JSON and the `content[]` markdown trailer. Empty-result and truncation guidance now delivered via `ctx.enrich.notice()`.
- **`nvd_audit_cpe`** — `queryMeta.cpeName` / `queryMeta.virtualMatchString` consolidated into a single `enrichment.auditTarget` string (whichever CPE identifier was used for the query).
- **`@cyanheads/mcp-ts-core` ^0.9.13 → ^0.9.16** — enables `ctx.enrich` / `enrichmentTrailer` API; picks up enrichment linter rules (`enrichment-type`, `enrichment-prefer-block`, `enrichment-output-collision`, and related).

## Dependencies

- `@cyanheads/mcp-ts-core` ^0.9.13 → ^0.9.16
