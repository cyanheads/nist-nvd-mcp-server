# 0.1.4 — 2026-05-24

## Changed

- **All `package.json` scripts** migrated from `tsx` to `bun run` — `build`, `rebuild`, `clean`, `devcheck`, `tree`, `list-skills`, `lint:mcp`, `lint:packaging`, `changelog:build`, `changelog:check`. Scripts now invoke Bun's native TS runner rather than the tsx shim.
- **`start` / `start:stdio` / `start:http` scripts** switched from `node dist/index.js` to `bun dist/index.js` / `bun ./dist/index.js`.
- **`test` script** changed from `vitest run` to `bunx vitest run`.
- **`Dockerfile`** reverted from `node:24-slim` (which required an extra `npm install -g bun` step and used `./node_modules/.bin/tsx`) back to `oven/bun:1.3`. Build command simplified to `bun run build`.
- **`typescript`** bumped `^5.9.3 → ^6.0.3`.
- **`engines.bun`** tightened to `>=1.3.2` (matches `packageManager`).

## Removed

- **`tsx`** removed from `devDependencies` — replaced by Bun's native TS execution.

## Added

- **`funding` block** added to `package.json` (GitHub Sponsors + Buy Me a Coffee).
- **`packageManager: bun@1.3.2`** declared in `package.json`.
