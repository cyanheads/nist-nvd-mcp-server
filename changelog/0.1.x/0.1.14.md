# 0.1.14 — 2026-07-16

## Added

- **`filtersApplied`** — `nvd_search_cves` echoes the non-default filters a query actually applied (`keyword`, `severity` + `severityVersion`, `cweId`, `kevOnly` when true, `noRejected` when false) in the `enrichment` block, reaching both `structuredContent` and the `content[]` trailer. An empty or unexpectedly narrow result set becomes diagnosable without re-reading the request; absent when the query ran unfiltered. ([#19](https://github.com/cyanheads/nist-nvd-mcp-server/issues/19))
- **`severityMin` / `filteredCount`** — `nvd_audit_cpe` reports the active minimum-severity filter and how many CVEs it dropped from the page NVD returned. `filteredCount` counts against the fetched page (its size minus `returned`), never `totalCount` minus `returned` — CVEs beyond `limit` are never fetched, so charging them to the filter would overcount. Present only when `severityMin` is set. ([#19](https://github.com/cyanheads/nist-nvd-mcp-server/issues/19))
- **`filteredSeverity`** — `nvd_search_cves` brief records carry the severity at the CVSS version a `severity` filter matched on, surfaced only when it disagrees with the cross-version headline: a CVE scored v2 10.0 (HIGH — v2 has no CRITICAL tier) and v3.1 9.8 (CRITICAL) headlines as HIGH but matched a `severity=CRITICAL&severityVersion=v3` query on the 9.8. The cross-version `severity` headline is unchanged for callers that pass no filter. ([#24](https://github.com/cyanheads/nist-nvd-mcp-server/issues/24))

## Changed

- **Full-record descriptions default to English** — `normalizeCve` keeps only the English description, falling back to whatever exists when a record carries none (CNA rules require English on every entry), trimming multilingual payload from `nvd_get_cve` full-mode records and `nvd_audit_cpe`. A new `allLanguages` boolean input on both tools restores every localized description; the `nvd://cve/{cveId}` resource requests English-only to match the default. ([#23](https://github.com/cyanheads/nist-nvd-mcp-server/issues/23))

## Fixed

- **`rate_limited` advertised the wrong error code** — all five tools declared `ServiceUnavailable` (`-32000`) while a 403 is thrown as `RateLimited` (`-32003`) via `rateLimited()`. The declarations and `docs/design.md` now match the wire; the thrown code is unchanged. ([#25](https://github.com/cyanheads/nist-nvd-mcp-server/issues/25))
- **`nvd_get_cve` rendered blank descriptions for records with no English entry** — `format()` falls back to the first available description instead of leaving text-only clients empty when `descriptions.find((d) => d.lang === 'en')` finds nothing. ([#23](https://github.com/cyanheads/nist-nvd-mcp-server/issues/23))
