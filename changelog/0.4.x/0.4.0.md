# 0.4.0 — 2026-10-26

## Added

- **SSVC assessments** on full CVE lookups, audits, and the CVE resource retain contributor names, optional timestamps, ordered decision points, and array values. [#58](https://github.com/cyanheads/nist-nvd-mcp-server/issues/58)
- **Section selectors** add `includeConfigurations` to lookup and audit, and `includeReferences` to audit; false omits the selected field from both output surfaces. [#61](https://github.com/cyanheads/nist-nvd-mcp-server/issues/61)
- **`nist-nvd-guide`** ships with plugins, npm, MCPB, and Docker, and is readable at `skill://nist-nvd-guide/SKILL.md` for applicability, severity, and coverage workflows.
- **Effective date windows** in search `filtersApplied` include explicit and shorthand-expanded dates after clamping, allowing exact replay. [#49](https://github.com/cyanheads/nist-nvd-mcp-server/issues/49)

## Changed

- **`nvd_audit_cpe` output:** `configurationNodes` is optional when `includeConfigurations` is false; consumers must handle its absence. Default calls still include configurations.
- **Oversized reads** clamp by default to 2000 CVEs/events, 10000 CPEs, or the first 100 CVE IDs, with counts and notices; batch lookup reports `unprocessedIds`. `NVD_CLAMP_LIMITS=false` restores rejection and advertised maxima. [#57](https://github.com/cyanheads/nist-nvd-mcp-server/issues/57)
- **Plugin packaging** adds the Agent Plugins root manifests, validates published skills, and preserves runtime SDK skill modules during MCPB cleanup.

## Fixed

- **Full-record rendering** includes every selected description, reference, and CPE criterion on both surfaces, preserving literal Markdown text and usable links. [#52](https://github.com/cyanheads/nist-nvd-mcp-server/issues/52)
- **Audit severity thresholds** evaluate all CVSS severity bands, retaining CRITICAL records whose highest raw-score headline is HIGH. [#51](https://github.com/cyanheads/nist-nvd-mcp-server/issues/51)
- **Search string filters** are trimmed; blank values are omitted with a notice before companion validation. [#53](https://github.com/cyanheads/nist-nvd-mcp-server/issues/53)
- **Request lifetimes** keep deadlines and caller cancellation active through body reads; cancellation propagates through source lookup without populating its failure cache. [#54](https://github.com/cyanheads/nist-nvd-mcp-server/issues/54)
- **Invalid NVD responses** fail with nonretryable `nvd_invalid_response` instead of empty successes or missing-record errors; completed-body parsing and envelope validation do not retry. [#55](https://github.com/cyanheads/nist-nvd-mcp-server/issues/55)
- **Blocked NVD requests** return nonretryable `nvd_request_blocked` without a rate-limit backoff when the HTML block marker appears without `Retry-After`. [#59](https://github.com/cyanheads/nist-nvd-mcp-server/issues/59)
- **Search rejection recovery** names accepted case-sensitive CWE forms and full ISO datetime examples on both error surfaces. [#60](https://github.com/cyanheads/nist-nvd-mcp-server/issues/60)
